## 📌 About

QR Studio is a responsive web application designed to make QR code generation simple and convenient.

Users can enter different types of information, customize QR code appearance, preview changes instantly, and download QR codes as PNG images.

## ✨ Features

- 🌐 Generate QR codes for URLs.
- 📝 Generate QR codes for plain text.
- ✉️ Create email QR codes.
- 📞 Create phone number QR codes.
- 📶 Generate Wi-Fi QR codes.
- 🎨 Customize foreground and background colors.
- 📏 Adjust QR code size and margins.
- ⚙️ Configure error correction levels.
- 🖼️ Preview QR codes in real time.
- 📥 Download QR codes as PNG images.
- 💾 Save recent QR codes using browser local storage.
- 📱 Responsive desktop and mobile interface.
- 🌙 Light and dark themes.
- ✅ Input validation and readability guidance.

*Features should be considered complete only after they have been implemented and tested in the application.*

## 🚀 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### 1. Clone the repository

```bash
git clone https://github.com/Chinmay-byte-afk/Qr-Code-Generator.git
```

### 2. Open the project

```bash
cd Qr-Code-Generator
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 5. Build the application

```bash
npm run build
```

## 🔐 Privacy

QR codes are generated in the browser. Recent QR entries may be stored locally using the browser's Local Storage API.

Avoid encoding sensitive information in QR codes intended for public sharing.
